# PATHFINDER EDU — 로컬 상담 포털 사용설명서

## 실행
Windows 10/11에서 Python 3.12 이상을 설치한 후 압축을 풀고 `실행_윈도우.bat`를 더블클릭합니다. 크롬이나 엣지에서 `http://127.0.0.1:8765/`을 엽니다. 포트 사용 중이면 CMD에서 `set PF_PORT=8879` 다음 `py -3 server.py`를 실행하고 8879번 주소로 접속합니다.

**설치 전 유의:** 첫 실행에 관리자 사용자 `brans911`, 초기 비밀번호 `brans911!`가 생성됩니다. 요청한 시험 계정만을 위한 것이며 누구나 예측 가능한 값이므로 **관리자 첫 로그인 후 마이페이지에서 즉시 변경**하세요. 외부 IP에 서버를 공개하지 마세요. 배포 ZIP에는 계정 DB가 없습니다. 실행 후 SQLite DB `data/pathfinder.sqlite3`가 로컬에서 생성됩니다.

## 역할별 흐름

학생: 최초 회원가입(아이디·이름·출생연도·비밀번호·필수 안내 동의) → 학생 로그인 → 진학 목표 선택 → 학기별 성적 → 자체 168문항 → 학교/학과 목표 → 자동 분석 → 연간/월간/주간/일간 계획 → 계획 규칙 검토 → 상담 접수 → 결과지 수신 및 PDF 또는 DOCX 다운로드.

관리자: 관리자 로그인 → **즉시 초기 비밀번호 변경** → 상담 접수함 → 사례 선택 → 학교 유형/지원자격/학과·학습전략 기록 → 최종 상담 발행 → 학생은 '상담 접수·결과'에서 확인.

보고서는 PDF와 DOCX로 내보냅니다. DOCX는 한컴오피스 한글에서 열어 **HWP/HWPX로 다시 저장**할 수 있습니다. 네이티브 HWP 파일이나 자동 이메일 발송 기능은 아직 없습니다.

## 학교 데이터

공공데이터포털 https://www.data.go.kr/data/15021148/standard.do 에서 학교 CSV를 직접 다운로드하세요. 관리자는 학교 목록 CSV와 해당 원본 HTTPS URL을 등록할 수 있습니다. 또한 개별 학교의 전년도 모집인원·지원인원 표가 있는 경우 입결 CSV를 등록할 수 있습니다. 두 데이터는 별개입니다.

**아직 제공하지 않는 것:** 전국 모집요강 자동 수집/전수 검증, 학년도별 학생 개인 합격 확률, 대학별 공식 성적 환산, 검증된 공인 IQ 검사, 14세 미만 법정대리인 본인 확인, 실제 결제·구독 처리, 상용화 법률심사 완료.

## 자체 질문 168개

관심·진로 96개, 학습 습관 36개, 학교·가치관 24개, 추론 연습 12개. 흥미·습관 문항은 자기보고 설문으로 **공인 심리검사가 아닙니다**. 추론 연습은 **IQ 검사가 아니며 지능지수로 변환하지 않습니다**.

## AI 사용 범위

기본 계획 검토는 규칙 기반입니다. 선택 옵션을 사용하려면 환경변수 `OPENAI_API_KEY`를 서버 컴퓨터에 설정하고 학생이 외부 전송에 동의해야 합니다. 외부 API에는 학생부·성적·계정 식별정보가 아닌 **학습계획 내 목표와 공부시간만** 전송합니다. `OPENAI_MODEL`로 모델을 설정할 수 있습니다. API 키 미설정/실패 시 규칙 검토만 사용됩니다.

## 개인정보와 상용화

데모 서버는 HTTP 로컬 주소 전용이며 외부 서비스에 공개하면 안 됩니다. 비밀번호는 PBKDF2 해시로 보관하고, 로그인 세션은 메모리에 저장됩니다. 계정·성적·설문·계획·사례는 로컬 SQLite에 저장됩니다. 학생은 마이페이지에서 자신의 데이터를 삭제할 수 있습니다. 관리자·상담자 계정이 모든 원자료를 보관하는 구조이므로 보존정책, 암호화 저장, 접근 로그, 백업, 삭제 처리, 초상/학생부 취급, 개인정보처리방침, 미성년 법정대리인 인증, 결제/환불 약관, 보안심사 등이 실제 서비스에 별도로 필요합니다.

만 14세 미만은 본 시험 서비스 가입을 차단합니다. 14세 이상 미성년의 실제 상용서비스에 적용될 정책 역시 전문 검토가 필요합니다. 「초·중등교육법」상 학교생활기록 자료의 영업 목적 이용 제한이 있어 **유료 학생부 분석을 그대로 판매하면 안 됩니다**. 실제 학교생활기록부 원본 업로드 기능은 의도적으로 포함하지 않았습니다.

`월 10,900원`은 화면에 있는 **상품 아이디어**이며 결제·회원권 활성화는 없습니다.
