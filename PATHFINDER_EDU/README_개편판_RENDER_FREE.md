## 1. 이번 개편 핵심

기존 PATHFINDER EDU의 학생가입, 학습계획, 학교검색, 168문항 설문, 28개 AI 전문 모드, 관리자 상담, PDF/DOCX 결과지는 유지했습니다. 학생 UI는 필수 7단계로 정리하고, 전문 기능은 '추가 기능 펼치기' 뒤에 배치했습니다.

| 학생 단계 | 학생이 하는 일 | 화면에서 제공되는 도움 |
|---|---|---|
| 시작 | 앞으로 어떤 단계가 있는지 살펴보기 | 현재 학년·성적·세특·목표의 입력 현황 |
| 1. 기본정보 | 학년, 지역, 목표 연도, 학교·계열 | 학생 눈높이의 문구와 입력 예시 |
| 2. 성적 | 중학교: 원점수/성취도/석차등급 중 선택. 고교: 학기별 등급+성취도+학점 | 항목별 구분 저장, 임의 환산 금지, 서버 범위 검증 |
| 3. 생기부·세특 | 세특, 진로·자율·동아리, 독서·탐구를 과목별 입력 | 주제→본인 역할→방법→결과 중심 작성 예시 |
| 4. 목표 설정 | 희망 학교/학과, 주간 시간, 진학 경로 | 조건을 적고 공식 모집요강과 구별 |
| 5. AI 심층분석 | 28가지 주제에서 선택, 질문 작성·동의 | '분석 중' 표시, 응답 완료 표시, 상세 텍스트·저장 |
| 6. 전문상담 | 상담 주제·질문 입력, 세특 원문 제공 선택 | 접수 전 저장 → 기초분석 중 → 상담원 검토 → 결과 도착 |
| 7. 학습 캘린더 | 일/주 계획을 수정하고 완료 체크 | 12주 자동 초안, 실천률·월간 피드백 |

학교 DB는 제공받은 학교 위치 원본 약 12,004개입니다. 이는 학교명·주소 참고 정보이며 **최신 전형요강·학과 운영·합격점수·합격확률을 제공하지 않습니다.**

## 2. 매우 중요한 무료 배포 설계

**이전 ZIP에 있던 `plan: starter` / `disk: /var/data`는 Render 유료 구성입니다.** 이번 ZIP의 `render.yaml`은 `plan: free`와 외부 `DATABASE_URL`을 사용합니다.

- Render 무료 Web Service: 웹사이트 서버만 운용 (요금 $0, 제한 있음)
- Supabase 무료 PostgreSQL: 계정·성적·세특·계획표·상담결과 영구 저장 **후보** (무료 500MB 및 활동·일시정지 제한)
- OpenAI API: AI 분석 시 사용량에 따라 **별도 유료**. 호스팅이 무료여도 AI가 무료는 아닙니다.
- 학교 CSV 검색: 외부 API 없어도 내장 데이터로 검색 가능.
- Render Free는 15분 동안 트래픽이 없으면 잠들 수 있고 깨어날 때 지연됩니다.
- Render Free는 영구 디스크가 없습니다. SQLite 파일을 무료 Render 내부에 두면 서버 재시작에 따라 학생 데이터가 사라집니다.
- Supabase Free도 장기간 저활동이면 프로젝트가 일시 중지되고, 무료 자동 백업을 신뢰하면 안 됩니다.
- **개인정보를 수집하기 전에 시험 계정으로 배포·권한 테스트를 완료하세요.** 본 버전은 만 14세 미만 보호자 인증을 제공하지 않아 출생연도만으로 가입 가능성을 보수적으로 제한합니다.

공식 근거:
- https://render.com/docs/free
- https://supabase.com/pricing
- https://supabase.com/docs/guides/database/connecting-to-postgres
- https://supabase.com/docs/guides/platform/free-project-pausing

## 4. Supabase 무료 PostgreSQL 연결

1. https://supabase.com/dashboard 로그인 → **New project** → Free 프로젝트 생성
2. Database password에 길고 고유한 비밀번호를 설정합니다. 비밀번호를 잃어버리면 설정에서 재설정해야 합니다.
3. 프로젝트의 **Connect**를 열어 **Session pooler** 모드와 연결 문자열을 찾습니다. 일반적으로 포트는 `5432`입니다. (화면에 나온 호스트명을 그대로 사용.)
4. 연결 문자열 형태 예시 (예시일 뿐 실제 호스트가 아님):

   `postgresql://postgres.PROJECTREF:URL_ENCODED_PASSWORD@aws-0-REGION.pooler.supabase.com:5432/postgres`

5. `URL_ENCODED_PASSWORD`는 특수문자가 있는 비밀번호를 URL 인코딩한 값이어야 합니다. 비밀번호 전체와 URL을 채팅이나 GitHub에 붙여넣지 마세요.
6. 이 연결 문자열 전체를 Render 환경변수 `DATABASE_URL`에 입력합니다.
7. 서버는 PostgreSQL 접근 시 TLS(`sslmode=require`)를 요청합니다. **더 강한 인증서 검증이 필요한 운영환경이라면 서버 인증서 검증 및 최소 권한 DB 사용자 구성이 추가되어야 합니다.**
8. Supabase가 중지되거나 데이터베이스 비밀번호가 잘못되면 서비스가 실행되지 않습니다. 데이터 유실을 막기 위해 **무료 Render에서 임시 SQLite로 자동 전환하지 않습니다.**

**중요:** 무료 PostgreSQL의 백업은 이용자 책임입니다. 정기적으로 안전한 오프라인 위치로 데이터베이스를 내보내 보관하는 운영 절차를 따로 마련해야 합니다. 관리자 화면의 CSV 가져오기는 백업 기능이 아닙니다.

## 5. Render 무료 Web Service 배포

1. https://dashboard.render.com 로그인 → **New → Blueprint** 선택
2. GitHub 저장소 연결 → 이 저장소의 `render.yaml` 확인
3. 환경변수에서 아래 비밀값을 등록합니다.
4. 배포 완료 후 Render의 `https://서비스명.onrender.com/` 접속
5. 관리자는 **`https://서비스명.onrender.com/admin`** 로 접속합니다. 학생 로그인 화면에는 API/관리자 설정 메뉴가 나타나지 않습니다.
6. 관리자 최초 로그인 후 마이페이지에서 **관리자 비밀번호를 즉시 변경**하세요.
7. 학생에게는 메인 URL과 초대 코드만 전달합니다. 관리자 URL·비밀번호·API 키를 공유하지 않습니다.

### 필수 환경변수

| 이름 | 내용 | 주의 |
|---|---|---|
| `PF_PUBLIC_MODE` | `1` | 공용 HTTPS 실행 모드 |
| `DATABASE_URL` | Supabase Session Pooler 접속 URL | **반드시 외부 DB**. 학생 화면/파일에 노출 금지 |
| `PF_ADMIN_USER` | `brans911` 또는 별도 지정 | 최초 실행에만 사용자 생성 |
| `PF_ADMIN_PASSWORD` | 16자 이상 임시 강력 암호 | 배포 전 직접 생성, 초기 비밀번호 사용 금지 |
| `PF_SIGNUP_CODE` | 12자 이상 초대코드 | 20명에게 별도로 전달 (보안상 외부 공개 금지) |
| `PF_MAX_STUDENTS` | `25` | 시범 학생 정원 제한 |

### 선택 환경변수

| 이름 | 내용 |
|---|---|
| `OPENAI_API_KEY` | `sk-...` 형태의 OpenAI Secret Key; 관리자 전용, 학생에게 절대 제공 금지 |
| `OPENAI_MODEL` | 현재 프로젝트에서 권한이 확인된 모델명. 기본 `gpt-4.1-mini` |
| `PF_AI_CONCURRENCY` | 동시에 실행되는 AI 호출 수 (기본 2). 20명 접속=20개 AI 요청 동시 처리 아님 |
| `PF_AI_MAX_OUTPUT_TOKENS` | 최대 AI 답변 출력 토큰 (기본 4500). 길수록 비용·응답시간 증가 |
| `NEIS_API_KEY` | 나이스 학교 기본정보용 인증키 |
| `DATA_GO_KR_API_KEY` | 공공데이터포털 대학 기본정보 인증키 |

보안 원칙: OpenAI Secret Key나 DB 비밀번호는 브라우저 JS·HTML·GitHub에 입력하지 않습니다. Render 서비스 → **Environment**에서만 등록·교체합니다. OpenAI Tracking은 서버의 관리자 전용 API 사용량 화면에서 확인합니다.

## 6. 학생이 입력하는 실제 예시

**중3 1학기 성적:** '2. 성적 입력'에서 `3-1` 학기 선택 → 수학: 성취도 / A, 과학: 원점수 / 92, 영어: 성취도 / B처럼 과목별로 구분해 입력합니다. 이들은 서로 다른 기준이므로 숫자로 환산하지 않습니다. 입력 값이 수치가 아닐 때도 그대로 저장됩니다.

**고1 성적:** 고교 학기를 선택하고 과목 `공통수학1`, 등급 `2등급`, 성취도 `A`, 학점 `4`를 각각 입력합니다. 5등급제와 9등급제는 교육과정·입학학년도·과목별 적용 여부를 확인하세요.

**과학 세특:** 카테고리 `세특`, 과목 `과학`, 학기 `중3-1`, 내용 `산화·연소 실험에서 온도·산소 공급을 통제하여 반응 변화를 관찰하고 결과를 표로 정리함`처럼 **실제로 수행한 내용만** 기재합니다.

**전문상담원에게 의뢰:** '6. 전문상담'에서 구체적으로 알고 싶은 고교·전형·성적 부족 영역·월별 학습을 적고 제출합니다. 상담 건별 세특 원문 공유를 원하면 별도 체크합니다.

상태 흐름은 다음과 같습니다.

`접수 준비/저장 중` → `기초 분석 중` → `접수 완료(상담원 대기)` → `관리자가 검토 중` → `관리자가 발행한 최종 상담 도착`

**화면의 '기초 분석 완료'는 전문상담원의 상담 완료가 아닙니다.** 자동으로 사람처럼 완료된 척 표시하지 않습니다. 관리자 발행 전에는 최종 결과지를 볼 수 없습니다.

관리자는 상담 건별로 근거 원문, 강점, 위험, 학교자격, 진로, 세특, 과목별 처방, 12주 실행표, 면접, 보호자 안내, 즉시 행동, 재평가를 포함하는 13개 영역을 작성할 수 있습니다. 최소 종합 평가 및 학교 검토 분량을 충족해야 결과지를 발행할 수 있습니다.

## 7. 개인정보·보안 설계 및 제한

**구현한 통제**
- 관리자 전용 URL `/admin`과 학생용 URL `/` 분리. 학생 내비게이션에는 API/관리자 도구 링크 없음.
- 관리자 API 설정, 전체 학생목록, 다른 학생 상담, 최종 발행은 **서버 역할 검사**로 차단.
- 학생별 성적·세특·상담 정보는 계정 ID로 분리해서 조회.
- 본인의 세특 원문을 실제 상담원에게 전달할지 상담 건별 선택 동의.
- 외부 OpenAI 호출에서는 기본적으로 세특·학적 실명·계정 ID·생년월일을 제거. 원점수·성취도·등급의 **요약 정보와 사용자가 쓴 질문은 전송될 수 있음**.
- 세션 쿠키 HttpOnly, 온라인일 때 Secure, SameSite=Strict; CSRF 검사, 기본 입력 검증, 접근거부·프레임 차단·캐시 방지.
- 학생 가입 인원 및 API 요청 수 제한; AI 호출 동시 처리 2건, 학생당 일일 제한.
- API 환경변수 비밀 설정, API 테스트·키 확인은 관리자만.
- SQL 매개변수 바인딩, SQLite 로컬 테스트 모드와 PostgreSQL 온라인 모드 구분.
- 서버 예외가 발생할 때 온라인 사용자에게 DB 연결문자열이나 내부 경로를 그대로 보내지 않도록 처리.

**여전히 필요한 상용 운영 조치**
- 독립적인 코드 보안 감사, 취약점 분석·침투 테스트, 인증 우회/계정탈취 대응.
- 실제 개인정보 처리방침 및 동의 이력, 이용약관, 자료 보유기간, 위탁/해외전송 검토.
- 만 14세 미만 법정대리인 동의 및 확인, 생년월일 기준 연령 확인.
- 2단계 인증(MFA), 계정 복구, 관리자 접근 기록 검토, 비밀키 순환.
- 관리자 분실·침해 대응 절차, 정기 DB 백업·암호화 및 복구 훈련.
- 외부 API 비용 상한, 장문 요청 대기열, 20명 이상의 실제 동시 접속 부하 테스트.

**따라서 본 ZIP은 실제 미성년자 개인정보를 받는 정식 상용 서비스가 아닌 비공개 테스트용입니다.**

## 8. 자주 발생하는 오류

- **Render 502/서버 시작 실패**: `DATABASE_URL`이 비었거나 Supabase 비밀번호·호스트·포트가 다름. 서비스 Logs 확인. 절대 URL 전체를 공유하지 말고 연결 오류 코드만 공유.
- **첫 접속이 느림**: Render 무료 서버가 15분 비활동 후 잠들었다가 재시작하는 과정일 수 있음.
- **가입코드 오류**: `PF_SIGNUP_CODE` 확인. 대소문자·공백이 그대로 비교됨.
- **회원가입 차단**: 현재 버전은 출생연도만 입력하므로 보수적으로 만 14세 이상임이 명백한 출생연도만 허용함. 보호자 확인 기능 없음.
- **OpenAI 실패(401)**: 키 만료/오타/다른 프로젝트 권한.
- **OpenAI 실패(429)**: 잔액·할당량·일시 속도 한도 확인.
- **AI 비용**: Render 무료 ≠ AI API 무료. 대시보드에서 지출 한도 설정.
- **분석 중 표시 뒤 실패**: 네트워크 타임아웃·모델 접근·API 크레딧 등을 점검. 실패해도 상담원이 검토 완료한 것처럼 표시하지 않음.
- **상담 접수는 되었지만 결과 없음**: 관리자가 `/admin`에서 접수 건을 열어 상세 상담을 작성·발행해야 결과가 생깁니다.
- **재배포 후 로그아웃됨**: 로그인 세션은 프로세스 메모리 저장이므로 재시작 후 다시 로그인 필요. 외부 PostgreSQL에 저장된 학업 데이터는 유지됩니다.
- **Supabase 일시정지**: 무료 프로젝트 활동이 부족하면 중지될 수 있습니다. 대시보드에서 재개합니다.
