이전 터미널 키 입력 방식은 변경되었습니다. 아래의 **Secret Key / Tracking 관리자 연결 가이드**를 따르세요.

# PATHFINDER EDU PLUS — Secret Key / Tracking 관리자 연결 가이드

**버전: 2026-10-26 API 키 관리 개선판.** 로컬 Windows 10/11 PC에서 시험 실행하는 프로그램입니다. 상용 공개 서버 보안 심사를 마친 제품이 아닙니다.

## 핵심 구분

- **OpenAI Secret Key (`sk-`로 시작)**: AI를 실제 호출할 때 쓰는 비밀 인증키입니다. 관리자만 등록합니다.
- **Tracking (사용량 추적)**: API 사용량에 관한 기능입니다. **OpenAI에 별도의 'Tracking API Secret Key'가 있는 것이 아닙니다.** OpenAI 프로젝트별 사용량은 https://platform.openai.com/usage 에서 확인하고, 이 프로그램의 `관리자 → API 키·사용량 관리`에는 자체 호출 횟수·성공/오류 건수·토큰 수의 집계가 표시됩니다.
- **NEIS 인증키**: https://open.neis.go.kr/ 에서 발급받는 학교정보 요청용 키입니다. OpenAI Secret Key와는 서로 다릅니다.
- **공공데이터포털 서비스키**: https://www.data.go.kr/data/15107736/standard.do 에서 대학 기본정보 API 활용신청 후 발급. 포털에서 인코딩형/디코딩형을 제공하면 둘 다 입력할 수 있도록 저장 시 정규화합니다.
- Google Analytics 등의 제3자 웹 방문 추적용 식별자를 뜻했다면, 그것은 **OpenAI API Tracking과 다른 서비스**입니다. 현재 이 시제품은 외부 웹 방문자 추적 스크립트를 설치하지 않으며 서버 사용량 집계만 기록합니다.

## 실제 연결 단계

1. ZIP을 **모두 압축 해제**합니다. HTML을 직접 열지 않습니다.
2. PC에 Python 3.12 이상 설치 후 폴더 내 `실행_윈도우.bat` 또는 `관리자_API설정_실행.bat` 더블클릭.
3. Chrome/Edge에서 `http://127.0.0.1:8765/` 접속.
4. **관리자 로그인**. 첫 로그인이라면 기존 관리자 계정으로 로그인하고 **마이페이지에서 초기 비밀번호를 먼저 변경**해야 API 키 저장이 열립니다. 초기 비밀번호가 담긴 ZIP을 다른 사람에게 배포하지 마세요.
5. 좌측 `API 키·사용량 관리` 메뉴 선택.
6. OpenAI API 키 페이지 https://platform.openai.com/api-keys 에서 **Project → API Keys → Create new secret key**를 선택해 새로운 프로젝트 Secret Key 생성. 키는 생성 시 전체 값이 한 번만 표시되므로 안전하게 보관하세요. ChatGPT 구독과 API 결제는 별개입니다.
7. 프로그램 `OpenAI Secret Key` 입력에 붙여넣기. 원하는 모델 이름을 입력(기본 `gpt-4.1-mini`).
8. 나이스 및 공공데이터포털 키가 있다면 각각 별도 입력칸에 붙여넣기. 없다면 빈칸을 유지합니다.
9. **현재 관리자 비밀번호**를 다시 입력하고 `API 설정 안전 저장` 선택. 비워둔 키는 기존 값을 유지하며 삭제 체크는 해당 저장 키를 제거합니다.
10. `OpenAI 테스트`를 클릭. **실제 인터넷이 연결돼 있어야** 합니다. 성공 시 인증 확인 메시지를 표시합니다. 모델 사용 가능 여부는 학생의 AI 분석 요청 시 추가 확인됩니다.
11. 학생 계정에서 `AI 전문가 28종` → 분석 모드 선택 → 질문 입력 → 축약된 학습정보 전송 동의 → 분석 요청. 모델 사용 시 과금될 수 있으므로 프로젝트의 예산 상한도 설정합니다.
12. 관리자 페이지 아래 `API Tracking 대시보드`에서 호출 건수, 토큰 사용량, 성공·오류 건수를 조회합니다. 공식 결제 금액은 OpenAI Usage/Billing에서 확인합니다.

## Secret Key가 저장되는 위치·방법

- **Windows**: `PATHFINDER_EDU/data/.api_credentials.dpapi`에 **Windows DPAPI(CurrentUser)** 암호화 형태로 저장합니다. 동일 PC라도 다른 Windows 사용자 계정에서는 보통 복호화할 수 없습니다. 데이터를 다른 PC/사용자로 복사하면 열리지 않을 수 있으므로 키를 새로 발급해야 합니다.
- **macOS·Linux**: 영구 저장을 자동으로 시도하지 않습니다. 관리자 입력 키는 **서버 프로세스 메모리에만** 유지됩니다. 재시작 후에는 서버 환경변수(`OPENAI_API_KEY`, `NEIS_API_KEY`, `DATA_GO_KR_API_KEY`)를 별도로 설정합니다. Windows의 DPAPI 기능을 Linux에서 지원한다고 표시하지 않습니다.
- **환경변수 우선**: 이미 서버 환경변수에 설정된 키가 있으면 관리자 UI에서 저장한 키보다 우선합니다. 해당 환경변수는 프로그램 내 삭제 버튼으로 해제할 수 없습니다. 서버 실행 환경에서 제거해야 합니다.
- **공통**: 키 전체는 학생 화면, 비밀 키 등록 후의 관리자 화면, API 응답, 사용량 DB, 생성 ZIP에 표시하거나 포함하지 않습니다. 브라우저에서 입력한 Secret Key는 로컬 HTTP 요청을 통해 서버로 전달되므로 본 프로그램은 **127.0.0.1 로컬에서만** 사용하세요. 외부망 운영에는 HTTPS, 전용 키 관리 서비스, 사용자 권한·접근 로그·보안 검증이 필요합니다.
- OpenAI Secret Key는 서비스를 제공하는 서버에만 보관하세요. 브라우저 스크립트나 Git 저장소에 넣지 마세요. 키 노출이 의심되면 OpenAI에서 폐기·재발급합니다.

## 테스트와 오류

| 메시지 | 확인할 것 |
|---|---|
| 초기 관리자 비밀번호 변경 필요 | `마이페이지`에서 새 비밀번호로 변경 후 API 저장 |
| OpenAI: 키 등록됨 · 인증 실패 | 실제 키인지, 프로젝트 권한·과금·네트워크 제한을 확인 |
| 401 | 키가 잘못됐거나 취소됐을 수 있음 |
| 429 | 요금 한도 / 사용량 한도 / 속도 제한 가능성 |
| 모델 관련 400 | 해당 모델명이 실제 허용되는지 확인 |
| API 키 등록 성공인데 예전 키로 호출 | Windows 환경변수가 우선하는지 확인 |
| Windows 계정 변경 후 설정 파일 열 수 없음 | 같은 계정에서 실행하거나 키 재발급 후 이전 암호화 파일을 안전하게 따로 보관/삭제 |
| 학교/대학 API '연결 성공' | 학교 기본정보 조회 여부만 확인. 전형 자료나 개별 입결은 별도 확보 필요 |

**Tracking 주의:** 대시보드의 토큰 사용량은 서버로 반환된 API 사용량 데이터 기반입니다. 현금 과금액은 추측하지 않습니다. 연결 테스트 호출도 건수에는 포함될 수 있습니다. 추적 테이블에는 개인별 질문 텍스트·API 비밀키·학생 식별자를 기록하지 않습니다.
