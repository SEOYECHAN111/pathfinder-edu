# PATHFINDER EDU · 주간 캘린더 / 진학 분석 / PDF 개선

## Windows 실행

1. Windows 10 또는 11에 Python 3.12(64비트) 설치.
2. ZIP을 `압축 풀기` 하고 `PATHFINDER_EDU\실행_윈도우.bat` 더블클릭.
3. 배치파일이 PDF·DOCX용 필수 패키지(`reportlab`, `python-docx`)를 확인하고, 필요 시 `pip`로 설치합니다. 인터넷 연결이 필요할 수 있습니다.
4. `http://127.0.0.1:8765/` 접속. **로컬 시험용**이며 외부에 서버 포트를 공개하지 마세요.
5. 관리자 최초 ID는 `brans911`로 설정되어 있으며, 이전에 지정한 시험 비밀번호로 로그인할 수 있습니다. 로그인 뒤 즉시 비밀번호를 변경하세요.

## 학생: 주간 캘린더

학생 로그인 → `06 · 학습계획·캘린더` → 아래로 내려 주간 캘린더에서 날짜별 `+ 계획 추가`.
과목 / 학습 목표 / 분 단위 시간 입력 → `계획에 추가·수정` → `캘린더 서버에 저장`.
등록한 과제는 `수정`, `삭제`, `완료 체크`, 다른 요일로 끌어서 이동할 수 있습니다.
상단 `지난주`, `다음주`, `이번주`로 주차 이동. 연간/월간/주간/일간 텍스트 목표도 계속 사용 가능합니다.
`목표 연결·부담 검토`를 누르면 계획 내용과 일정 부담을 검토합니다. 서버는 완료된 시간/등록 시간을 기준으로 실행률을 산출합니다. 이 실행률은 **입시 합격확률이 아닙니다**.

## 학교·대학별 진학 경로

`목표·진학 분석 그래프`에서 성적 추이, 진로 설문 응답 비율, 실행률, 목표 구체성을 확인합니다.
광주 2027 고입 공식 계획에 등장하는 학교 유형 예시 17건을 등록해, 전국학교 CSV가 없어도 광주 학교 유형을 참고할 수 있습니다. 2027 계획을 2028 이후 확정 요강으로 간주하지 마세요.
전국학교 전체는 관리자 `공식 학교 자료 등록`에서 국가 공공데이터 CSV를 가져와 DB에 저장할 수 있습니다.
- 전국 초·중·고: https://www.data.go.kr/data/15021148/standard.do (학교명·주소·학교급; **합격선 정보 아님**)
- 고입: https://www.hischool.go.kr/
- 공식 광주 2027 기본계획: https://www.gen.go.kr/xboard/board.php?keyset=&mode=downpost&number=454012&page=1&sCat=0&searchword=&tbnum=20
- 대입: https://www.adiga.kr/
- 2028년 전국 194개 대학 시행계획 발표: https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=106040&lev=0&m=020402&opType=N&page=1&s=moe&statusYN=W

특히 **중학생 장기 대입의 '현재 상태 유지 시 어느 대학에 합격 가능한가?'**를 숫자로 제시할 검증된 데이터가 없습니다. 중학교 성적을 대학별 입결에 바로 연결하면 허위 예측이 됩니다. 목표 대학 목록과 목표 학과를 학생과 관리자 상담을 통해 정한 다음, **그 대학의 해당 학년도 원문 지원조건**을 검토해야 합니다. 현재 그래프의 백분율은 학업/진로 자료의 충실도, 완료 일정의 실행률이며 **개인 합격 확률을 표시하지 않습니다**.

## PDF 오류 수정

기존 고정길이 문자열 줄바꿈과 한글 폰트 누락 가능성 때문에 PDF 텍스트가 잘리거나 깨질 수 있었습니다. 출력기를 교체해 환경별 한국어 폰트를 자동 선택하고, 긴 문장·목표 목록을 자동 페이지 분할하며, 그래프와 학생의 학습 일정을 포함합니다.

학생이 상담 요청을 제출하고 **관리자가 결과를 발행한 뒤** `07 · 상담 접수·결과`의 `PDF` 버튼으로 내려받습니다. 관리자는 `상담 접수함`에서 검토 중인 사례의 PDF 다운로드도 가능합니다. 한글 호환 DOCX는 한글 프로그램에서 열어 HWP/HWPX로 별도 저장할 수 있습니다. 이 패키지는 HWP 네이티브 생성기를 제공하지 않습니다.

## 개인정보·상용화 제한

- 현재 학생·관리자 로컬 계정과 SQLite 데이터는 암호화된 서버 저장소나 정식 온라인 호스팅이 아닙니다.
- 미성년자 법정대리인 검증 미구현: 14세 미만 가입 제한.
- 계정 삭제는 학생 마이페이지에서 가능.
- AI 학습 계획 검토는 별도 API 설정과 명시적 동의 때만 동작. **성적·학생부는 외부 AI API에 전송하지 않음.**
- 관리자 최초 비밀번호는 예측 가능하므로 즉시 변경.
- 일부 공공자료는 별도 API 이용조건 검토 필요.
- 개인 합격예측 모델, 2030학년도 확정 대학별 원서 정보, 상용 결제 시스템은 미구현.
