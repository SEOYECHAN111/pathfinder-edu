# PATHFINDER EDU PLUS — API 호출 실패 수정판 (2026-10-27)

## 이번 수정

이전 판의 `OpenAI 테스트`는 `/v1/models` 인증만 확인해서 실제 답변 생성(`/v1/responses`)의 실패 원인을 확인할 수 없었습니다.
이번 판에서는 **선택한 모델로 작은 테스트 메시지를 보내 실제 AI 답변이 생성되는지 확인**합니다. 테스트도 사용량에 반영되고 소량 과금될 수 있습니다.

관리자 → API 키·사용량 관리 → `OpenAI 실제 AI 생성 테스트`를 눌러 결과 메시지를 확인하세요.
기존 설정 키가 있다면 다시 입력하지 않아도 됩니다. Windows 같은 사용자 계정의 암호화 저장 파일(`data/.api_credentials.dpapi`)을 계속 사용합니다. ZIP을 새로운 폴더에 풀면 **기존에 입력한 키/데이터는 자동 복사되지 않습니다.** 기존 폴더를 백업 후 수정 파일만 덮어씌우거나, 새 폴더에서 재등록하세요.

## 최초 확인 순서

1. `관리자_API설정_실행.bat`로 실행 (`http://127.0.0.1:8765/` 접속). `file://`로 HTML만 열지 마세요.
2. 관리자 로그인 → 마이페이지에서 초기 비밀번호 변경 → `API 키·사용량 관리`.
3. `OpenAI Secret Key`에 OpenAI 프로젝트의 실제 `sk-...` 키 전체를 붙여 넣고, `AI 모델`은 우선 `gpt-4.1-mini`로 입력하세요.
4. **현재 관리자 로그인 비밀번호**를 아래에 다시 입력하고 `API 설정 안전 저장` 클릭.
5. `OpenAI 실제 AI 생성 테스트` 클릭. 이제 인증뿐 아니라 실제 응답까지 검사됩니다.
6. 학생 계정 로그인 → `AI 전문가 28종` → 외부 데이터 전송 동의 체크 → 요청 실행.

**API 키를 채팅이나 스크린샷으로 보내지 마세요.** 오류코드와 메시지만 공유하세요.

## 결과별 진단

- `키 미등록`: 서버 내 키가 없는 상태. 새 ZIP 폴더를 열었다면 키를 다시 등록해야 함.
- `환경변수 키가 우선 적용됨`: Windows 또는 터미널에서 `OPENAI_API_KEY`가 남아 있어서 관리자 새 키가 적용되지 않을 수 있음. 환경변수 제거 후 서버 재시작.
- `HTTP 401`: 만료/폐기/복사 실수 등 Secret Key 문제.
- `HTTP 403`: 프로젝트 권한 또는 모델 엔드포인트 접근 문제.
- `HTTP 404 / model_not_found`: 모델명 또는 프로젝트에서 사용할 수 없는 모델.
- `HTTP 429 / insufficient_quota`: 크레딧·지출·사용 한도 확인. ChatGPT Plus와 API 결제는 별개. https://platform.openai.com/settings/organization/billing/overview
- `HTTP 429 / rate_limit_exceeded`: 요청 속도 또는 토큰 한도. https://platform.openai.com/settings/organization/limits
- `network_error`: 인터넷, 방화벽, 프록시, SSL 환경 확인.
- `AI 출력 토큰 한도`: 모델/토큰 설정 확인.
- `보안 확인 실패`: 새로고침 후 재로그인.
- `초기 관리자 비밀번호 변경 필요`: 마이페이지에서 변경해야 키 저장 가능.
- `API 키가 등록됨`은 인증 성공 의미가 아님. 반드시 실생성 테스트 필요.

## 배포 범위

로컬 Windows 데모에서 동작하도록 만든 수정판입니다. 실제 OpenAI Secret Key가 제공되지 않았으므로 외부 OpenAI 서비스 실연결을 직접 검증하지 않았습니다. 테스트는 모의 HTTP 응답과 로컬 서버를 이용해 검증했습니다. 로컬 계정 파일 및 키는 ZIP에 포함하지 않습니다.
