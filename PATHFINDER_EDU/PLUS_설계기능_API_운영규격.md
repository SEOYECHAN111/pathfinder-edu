# PATHFINDER EDU PLUS: 개발자·운영자 기술 명세

## 기존 코드 유지/확장 정책

원본 서버(`server.py`), `engine.py`의 과목/진로/고교유형 규칙, `enhancement_core.py`의 캘린더 검증, `question_bank.py`의 168문항, PDF/DOCX 관리 및 로그인·상담 로직을 유지합니다. 확장 파일:

- `ai_suite.py`: 전국 학교 DB 변환/검색, 적합도 휴리스틱, 로컬 진단, 12주 캘린더, 개인 데이터 최소화, 28개 전문 AI 역할, OpenAI Responses API, 나이스 기본정보 API, 대학 기본정보 API.
- `app_plus.js`: AI 스튜디오, 자동계획·승인, 전국학교 조회/비교, 대학조회, 실적 대시보드, API 설정 안내.
- `styles_plus.css`: 2열 작업영역, 모바일 반응형, 인쇄용 결과 출력.
- `data/national_schools.csv`: 이용자가 제공한 원본 CP949 CSV. DB는 첫 실행 시 생성.
- `tests/test_plus.py`: API 비활성, 학생 식별정보 축약, 12주 계획, 학교 지역분리, 추천 지표 및 모의 API 응답 단위 테스트.

## 새 API 계약

모든 아래 엔드포인트는 기존 `pf_session` HttpOnly 쿠키와 계정 권한이 필요합니다. POST는 `X-CSRF` 헤더가 필수입니다. `GET` 중 `/api/v2/status`는 로그인된 학생/관리자 모두 조회할 수 있습니다.

| 메서드 | 경로 | 핵심 인자 | 결과 |
|---|---|---|---|
| GET | `/api/v2/status` | 없음 | API 키 존재 여부만 boolean, 학교 수, AI 28모드, 모델명 (키 문자열 비노출) |
| GET | `/api/v2/schools` | q, region, level, limit, offset | 전국 12,004개 학교 중 제한된 페이지, 메타데이터, 원문 출처 |
| GET | `/api/v2/recommend-schools` | q, region, limit | 로그인 학생 프로필 기반 자체 후보 탐색 점수, 항목별 가산점, 설명 |
| GET | `/api/v2/offline-analysis` | 없음 | 과목별 원점수 추세·학습 실행률·부족 입력항목, 합격률 `null` |

### 고입 학교 적합도 설명

`score_school()`은 0~100 범위의 **휴리스틱 탐색 점수**만 생성합니다. 계산 요소: 기존 생활권 지역 일치(최대 30), 학생이 목표로 지정한 학교(25), 학교명 단서와 선호 학교 유형 (최대 20), 해당되는 수학/과학 기록(10). 점수가 높다고 지원 자격이나 합격 가능성을 의미하지 않으며 공식 유형·학교 수준을 모르는 경우 근거 없음을 표시해야 합니다. `probability`는 `null`이 유일한 허용값입니다.

향후 지원자격 엔진은 지역 선발 기본계획, 학교별 요강 PDF에서 지원 요건을 추출하되 **교차검증된 데이터 + 원문 URL + 적용 학년도 + 확인일** 없이 '지원 가능' 결론을 표시해서는 안 됩니다.

### 개인정보 데이터 흐름

입력 프로필/성적/계획 → 서버 SQLite (이 PC 내부) → `explain_offline()` 통계 요약 → 이용자 체크박스 `externalConsent:true` 확인 → `payload_for_ai()` → 서버에서 HTTPS OpenAI 호출. 외부 데이터는 광역지역·현재학년·진학목표·전공·과목별 집계통계·실행률·사용자 작성 질문으로 한정합니다. 개인정보 정규식 1차 제거 및 길이 제한을 적용하지만 자유 텍스트 완전 익명화는 보장하지 않습니다. **동의하지 않으면 외부 호출 코드가 실행되지 않습니다.**

OpenAI API는 `store:false`를 보내고, 모든 키는 `os.getenv()`로 읽습니다. 결과 및 질문은 해당 학생 계정 전용 SQLite `ai_history`에 저장합니다. 계정 삭제 시 해당 기록을 함께 지웁니다. 데이터보호법 및 미성년자 인증 준비 없이 인터넷 배포를 금합니다.

### API 실패·요금 제한

- OpenAI HTTP 401/403/429/5xx는 비밀키·원시 응답 전문을 브라우저에 표시하지 않고 한국어 메시지를 반환합니다.
- 입력 질문 2,500자 제한, 기본 최대 5,500 출력 토큰 (`PF_AI_MAX_OUTPUT_TOKENS`), 상한 7,000.
- 성공 요청 저장 횟수 기준 일 35회, 마지막 요청 간격 8초 (서버 프로세스 메모리 기준); 단, 다중 프로세스·서버 재시작을 포함한 **완전한 비용 상한은 아닙니다.** 실제 과금 한도는 제공자 프로젝트에서 별도 설정해야 합니다.
- 네트워크 타임아웃 기본 OpenAI 75초, 나이스 12초, 대학 20초. 오류가 발생해도 로컬 기능은 영향을 받지 않습니다.

### 자동 학습계획 설계

월요일부터 시작, 12주 동안 월~토 6세션/주, 기본 일요일 휴식, 주 1시간~50시간, 과목 우선순위는 현재의 최근 성적이 낮은 순서. 매주 다른 과목 로테이션, 기초진단(1~2주)→개념(3~5주)→유형(6~9주)→성과점검(10~12주). 학원·시험·생활시간표는 아직 자동 연동하지 않으므로 학생이 먼저 일정을 검토한 뒤만 저장합니다.

### 학교 데이터의 지역·유효기간 예외

업로드 CSV의 시도교육청 표기에 광주와 전남이 통합된 행정명칭이 있으므로, `region=광주`는 원본 도로명주소의 기존 광주 5개 구를 참고하여 고교를 필터하고, `region=전남`은 그 외 시군을 참고하여 표시합니다. 이것은 **지역 탐색 편의 기능**일 뿐 당시 법적 지원 권역을 정하지 않습니다. 기준일자 2026-10-01, 기관 페이지 수정일 2026-10-06 등 날짜의 의미를 구분합니다.

### 향후 상용화에 반드시 필요한 기능

1. 법정대리인 인증·개인정보 처리방침 및 DPA, HTTPS·강제 비밀번호 초기화·CSRF/보안 점검.
2. 전국 각 학교별 모집요강 파서 + 규칙 정규화 + 적용학년도·출처·확인일·버전 이력 + 입학처 검토 워크플로.
3. 정제된 대학·전형·학과·선택과목 원장 구축, 재수/N수 및 지역인재 지원자격 규칙 엔진.
4. 법적으로 허용되는 합격/불합격 라벨 수집 후 학년도별 시계열 검증, 확률 보정 및 신뢰구간. 현재 추정 확률 임의 표시는 금지.
5. 학습표 제약충족 최적화(학원/학교/시험/수면/휴식), 일정 충돌 탐지·리마인더 및 부모·학생 역할별 접근통제.
6. 업로드 문서 파서(PDF/DOCX/스캔), 학생부 원문 비공개 저장과 외부 AI 동의/마스킹·삭제 정책.
7. 고가용성 배포(PostgreSQL, 세션 서버저장, 백업/복구, 접근로그, API 요청 큐/요금 한도, 모니터링, 침투테스트).

이 명세는 현재 구현한 범위와 향후 확장 계획을 의도적으로 분리합니다.
