## 0. 가장 빠른 시작 (설치·키 없이 기본 기능 이용)

1. ZIP 전체를 다운로드하고 우클릭 → **모두 압축 풀기**. 폴더째 이동해야 합니다.
2. https://www.python.org/downloads/ 에서 Python 3.12 이상 설치. 설치 화면의 `Add python.exe to PATH`를 체크합니다. Windows에서 `py -3 --version`으로 버전을 확인합니다.
3. 압축을 푼 `PATHFINDER_EDU` 폴더에서 **`실행_윈도우.bat`**을 더블클릭합니다. 첫 실행 시 PDF/DOCX 관련 Python 패키지를 설치할 수 있으며 인터넷 연결이 필요할 수 있습니다.
4. 실행 창에 `http://127.0.0.1:8765/`가 표시되면 크롬 또는 엣지에 해당 주소를 입력합니다. 종료는 실행한 창에서 **Ctrl+C**.
5. 학생은 최초 회원가입(만 14세 이상) → 로그인 → 학적·6학기 성적 입력 → 목표학교·희망전공 등록 → 학교 검색 / 12주 계획 / 분석 대시보드 순서로 이용합니다.
6. 상담 관리자는 별도 관리자 탭에서 로그인합니다. 시험용 관리 계정 이름은 원본 설정에 따라 `brans911`이며 **최초 사용 직후 마이페이지에서 반드시 비밀번호를 변경**하세요. 초기 암호가 포함된 안내를 다른 사람에게 전달하지 마세요. 절대로 이 로컬 포트를 외부 인터넷에 노출하지 마세요.

이 단계에서 **AI API와 나이스 API는 없어도** 12,004개 학교 검색, 학습계획, 성적 그래프, 자체 설문, 학생별 로컬 분석, 관리자 상담/결과 발행, PDF/DOCX 기능을 사용할 수 있습니다.

## 2. OpenAI API 설정 — 가장 간단한 방법

1. OpenAI API 플랫폼의 공식 페이지 https://platform.openai.com/api-keys 에서 계정·프로젝트를 확인하고 새 API 키를 발급받습니다.
2. 필요한 API 과금·사용한도/결제수단은 https://platform.openai.com/settings/organization/billing/overview 에서 별도로 확인합니다. ChatGPT 구독과 API 비용은 별개입니다.
3. 열려 있는 PATHFINDER 서버를 Ctrl+C로 종료합니다.
4. 프로그램 폴더의 **`API키_입력후_실행.bat`** 실행.
5. 명령 프롬프트에서 `OpenAI API key (hidden)`이 나오면 발급받은 키를 붙여넣고 Enter. 입력 문자는 보이지 않으며, 프로그램은 키를 파일·DB·브라우저에 저장하지 않습니다. 입력 시 오류가 나면 Windows 명령 프롬프트를 사용하세요.
6. 이어 나오는 나이스 및 대학 API 키 질문은 없으면 그냥 Enter를 누릅니다.
7. 브라우저 접속 후 학생 로그인 → `API 연결·설정`에서 OpenAI: 설정 완료 여부 확인 → `AI 전문가 28종` → 전문가 선택 → 질문 입력 → 외부 전송에 별도 동의 → `심층 분석 요청`을 누릅니다.
8. **주의:** `설정 완료`는 환경변수 존재를 뜻합니다. 키 유효성·요금/모델 권한은 실제 요청 시 확인됩니다.

### API 모델과 출력 길이 설정

설정을 변경하고 싶다면 **Windows 명령 프롬프트(cmd)**에서 다음을 입력한 **같은 창**에서 실행할 수 있습니다. `YOUR_KEY` 등의 설명용 글자를 실제 키로 바꾸세요. 공유 화면이나 녹화 중에는 키 입력이 보이지 않도록 주의하세요.

```bat
cd /d "압축해제한_폴더\PATHFINDER_EDU"
set "OPENAI_MODEL=gpt-4.1-mini"
set "PF_AI_MAX_OUTPUT_TOKENS=5500"
py -3 api_launcher.py
```

`OPENAI_API_KEY`는 위 실행기가 별도의 숨김 입력으로 받습니다. `OPENAI_MODEL`은 사용하는 OpenAI 프로젝트에서 지원되는 모델 이름으로 교체할 수 있습니다. 응답이 너무 길거나 비용이 크면 `PF_AI_MAX_OUTPUT_TOKENS=2500` 등으로 줄일 수 있습니다(프로그램의 상한 7,000). 최대 출력 토큰은 답변 분량의 *상한*이고 모델이 언제나 그 길이만큼 출력하는 것은 아닙니다.

**보안:** 이 프로그램은 OpenAI Responses API `POST https://api.openai.com/v1/responses`를 서버에서 사용하며 `store:false`를 전달합니다. 키를 HTML, `app.js`, `app_plus.js`, 공유할 ZIP, 외부 Google 문서 등에 넣지 마세요. API 장애나 한도 초과 시에도 기존 오프라인 기능은 동작합니다.

## 3. 나이스 OpenAPI 연결

1. 공식 가이드 https://open.neis.go.kr/portal/guide/apiGuidePage.do 를 읽고 학교기본정보 API 인증키를 발급받으세요.
2. `API키_입력후_실행.bat`의 **두 번째** 숨김 질문에 NEIS 키 입력. OpenAI를 쓰지 않으면 첫 번째 키 입력란은 Enter로 건너뛰면 됩니다.
3. 학생 로그인 → `전국 학교 검색·비교` → `학교 이름 또는 주소`에 학교명 **2글자 이상** 입력 → `나이스 학교 정보 조회`.
4. 결과에는 학교명, 주소, 학교 종류, NEIS 학교코드, 교육청코드 등이 표시됩니다. 실제 전형/교과목 개설여부는 확인되지 않습니다.

대신 콘솔 환경변수로 입력할 때:

```bat
set "NEIS_API_KEY=발급받은_나이스키"
py -3 api_launcher.py
```

나이스가 지역·학교 코드(예: `ATPT_OFCDC_SC_CODE`, `SD_SCHUL_CODE`) 기반으로 제공하는 학사일정/시간표는 **학교의 다음 학년도 과목 편제표**와 다릅니다. 현재 본 버전에서 API 실시간 구현된 것은 **학교 기본정보 조회**입니다. 다른 나이스 API는 추가 구현이 필요합니다.

## 4. 공공데이터포털 대학 API 연결

1. https://www.data.go.kr/data/15107736/standard.do 접속 → 오픈 API에서 **전국대학및전문대학정보표준데이터** 활용 신청 → 본인 서비스키 발급.
2. `API키_입력후_실행.bat`의 세 번째 숨김 질문에 공공데이터포털 서비스키 입력(인증 제공 방식은 포털 안내에 따름).
3. 학생 로그인 → `전국 대학 공식 API` → 학교 이름 또는 시도명을 입력하고 조회.
4. 결과에 학교·대학교 구분, 캠퍼스, 주소, 설립 유형 등이 나오며 API에서 제공하지 않는 모집요강·학과별 전형자료는 표시하지 않습니다.

수동 환경변수 입력:

```bat
set "DATA_GO_KR_API_KEY=서비스키"
py -3 api_launcher.py
```

별도 대학별 학과정보 API: https://www.data.go.kr/data/15158666/openapi.do (승인·연동 추가 필요). 대입정보포털: https://www.adiga.kr/ (지원학년도별 **최종** 시행계획/모집요강 확인). 대학 공공데이터 API의 이용조건과 요청 제한을 준수하세요.

## 5. 학생 이용 순서 — 실제로 따라 하기

**가. 계정 생성**: 학생 회원가입 → 14세 이상 여부 확인 → 비밀번호 10자 이상 → 학생 로그인. 계정과 학습정보는 PC의 `data/pathfinder.sqlite3`에 저장됩니다.

**나. 학교·학업 정보 입력**: 학적/지역/학년/진학모드 → 중학교 1-1 ~ 3-2 학기별 성적 → (선택) 168문항 자체 진로 탐색 → 목표 고교·대학·전공 → 학습 가능 시간. 이 자체 설문은 공인 진로검사가 아닙니다.

**다. 학교 목록**: `전국 학교 검색·비교` → 검색조건 입력 → 내 목표와 맞는 고교 탐색. 탐색점수는 지역 일치 여부(최대 30), 사용자가 목표학교로 직접 지정한 경우(25), 학교명/선호분야 단서(최대 20), 입력된 수학·과학 점수 조건(10)의 가중 합으로 0~100 표시하는 **설명 가능한 자율 규칙**입니다. 해당 점수는 공식 평가가 아니며 90점이어도 입학할 확률 90%라는 뜻이 아닙니다. 학교 이름에 '과학고'가 들어간다는 이유만으로 해당 학교의 법적 유형을 확정하지 않습니다.

**라. 12주 일정**: `자동 12주 학습계획` → 주당 공부 시간 입력 → 12주 일정 미리보기 → `캘린더에 저장`을 직접 선택하면 72개 학습 세션이 저장됩니다. 기존 일정은 삭제하지 않으며 같은 생성 ID는 중복 추가하지 않습니다. 학원, 시험, 개인 일정을 **반드시 수동 조정**하세요. 생성/저장 API는 분리되어 있으므로 실수로 미리보기가 반영되지 않습니다.

**마. AI 컨설팅**: `AI 전문가 28종` → 질문 입력 → 개인 정보 입력 금지 → 외부 AI 전송 동의 → 실행. 결과는 화면에 긴 텍스트로 나오며 복사, TXT 저장, 인쇄 → PDF 저장이 가능합니다. 학생별 최근 20건 분석 기록을 볼 수 있습니다. 분석 전문가는 28가지 *역할/프롬프트*이며 독립 모델 28개를 설치한 것은 아닙니다.

**바. 상담·최종 결과지**: 학생이 상담 접수 → 관리자가 상담 접수함에서 직접 검토/수정 → 최종 결과 발행 → 학생 로그인 후 결과 열람 및 PDF/DOCX 다운로드. 외부 이메일/카카오톡 자동발송 기능은 제공하지 않습니다.

19. 탐구 프로젝트 설계: 실험·성과측정
20. 직업·진로 경로 탐색: 미래 필요역량·대안
21. 학습 실행 코치: 동기·행동 계획
22. 독서 분석 코치: 내용 검증·탐구 질문
23. 학부모 상담 요약: 격려·지원 원칙
24. 문제 해결형 AI 튜터: 단계별 힌트·풀이
25. 결정 검증과 반론: 위험·가정·반례
26. 장문 보고서 작성: 세부 근거·위험·실행
27. 주간 성과 리뷰: 계획 완료율 기반 진단
28. 상담 질문 생성: 관리자 확인목록

현재 모델 입력은 **계정 이름·생년월일·원문 학생부가 아닌 과목별 통계**, 광역지역, 학교 목표, 희망전공, 주간시간, 과제 완료 요약, 사용자가 입력한 자유 텍스트 질문으로 제한합니다. 자유 질문에서 전화번호·이메일·주민등록번호 형태는 1차 제거하지만 완전 익명화를 보장하지 않습니다. 질문·답변은 학생의 로컬 `ai_history` 테이블에 저장되므로 입력문에 개인정보를 적지 않는 것이 안전합니다.

## 7. 합격률과 적합도 산정 — 중요한 데이터 품질 정책

**이 버전에서 개인 합격률은 계산하지 않습니다.** 그 이유는 제공된 자료가 전국 초중등학교 기본 *위치* 정보이기 때문입니다. 지원자 개별 합격/불합격 레이블, 연도별 선발방식 변화, 자격요건·내신반영·점수분포가 없으면 확률 예측을 검증할 수 없습니다. AI에게 '확률을 직접 쓰라'고 지시해도 모델 프롬프트가 허구 수치를 생성하지 않도록 제한했습니다.

실제 추정확률 엔진을 운영하려면 다음 단계가 필요합니다.

- 대상 학교·학과·전형별 합격/불합격 사례를 적법한 동의와 최소수집 원칙에 따라 확보
- 학년도·전형·지역·학력/교과 기준을 정규화하고 동일 집단에 비교 가능한 점수로 변환
- 과거 연도 학습/미래 연도 검증 분리, 표본 부족 구간은 숫자 표시 금지
- 결과의 **보정(calibration)**, 예측 오류(Brier score 등), 연도별 분포 변화 검사
- 교차 검증·불확실성 구간·범위를 표시하고 관리자가 학교별 요강 확인 후 발행

입학경쟁률(지원자수/모집인원), 개인 합격률, 자체 탐색 적합도, 학습목표 실행률은 **서로 다른 지표**이며 절대 섞어서는 안 됩니다.

## 8. 운영 제한·오류 대처

**서버에 연결되지 않음** — `실행_윈도우.bat` 창이 계속 열려 있는지, `http://127.0.0.1:8765/`로 접속했는지 확인합니다. 포트 8765 사용 중이면 `set PF_PORT=8879` 후 `py -3 server.py` 실행하고 8879번 접속.

**API 키가 없다고 표시됨** — API 입력창에 키를 넣었다고 해도 서버를 별도 일반 실행 배치로 재실행하면 키가 없어집니다. `API키_입력후_실행.bat`에서 키를 다시 입력하세요. 키는 세션 중 메모리/자식 프로세스 환경변수에만 존재합니다.

**OpenAI 인증 실패/429** — 키 유효성, 과금 한도/프로젝트 권한, 모델 이름, 과도한 호출 빈도를 확인합니다. 프로그램은 API 실패의 대부분을 의미 있는 오류 메시지로 반환합니다. 기본 호출 간격 8초, 성공 기록 1일 35건(사용자별)입니다. 성공/실패를 포함한 모든 API 비용은 사용자 프로젝트에 청구될 수 있습니다.

**PDF 오류** — 기존 관리자가 최종 보고서를 발행한 다음 학생 마이페이지에서 PDF/DOCX 다운로드를 시도하세요. `reportlab`과 `python-docx` 설치 여부를 확인합니다. AI 답변은 `인쇄·PDF` 버튼으로 브라우저의 PDF 저장을 사용합니다. 단독 HTML로 열면 서버 기반 보고서 다운로드가 동작하지 않습니다.

**관리자 비밀번호 변경** — 최초 계정 비밀번호는 유추 가능할 수 있으므로 **반드시 변경**해야 합니다. 계정 DB와 API 키 모두 ZIP에 포함하지 않습니다.

**14세 미만 가입** — 법정대리인 인증 및 미성년 개인정보 수집 적법성 검토를 아직 구현하지 않았으므로 제한합니다. 상용화 전에 별도 검증이 필요합니다.

**오프라인** — 학교 목록·자체 분석·학습계획은 동작하나 외부 API·처음 필요한 의존성 설치는 동작하지 않습니다.

**테스트** — Python 개발 환경에서 `PYTHONPATH=. python -m pytest -q tests/test_plus.py tests/test_enhancement.py` (Windows cmd: `set PYTHONPATH=.` 후 실행). 서버 통합 테스트는 서버를 `set PF_PORT=8879`로 실행한 뒤 별도 창에서 `py -3 -m unittest discover -s tests -p test_end_to_end.py` 실행.
